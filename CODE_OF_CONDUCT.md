# Code of Conduct

CodePC Link aims to maintain a constructive, technical, and welcoming project environment.

Contributors are expected to:

- discuss ideas and code on their technical merits
- give specific, actionable feedback
- avoid harassment, personal attacks, discrimination, and deliberately disruptive behavior
- respect privacy and do not publish another person's private information
- handle security reports responsibly and privately

Project maintainers may edit or remove contributions, comments, or participation that materially violate these expectations. Serious or repeated violations may result in temporary or permanent exclusion from project spaces.

If you need to report conduct that should not be handled publicly, contact the repository owner privately.
